# 用量投递队列
python3 -m lab.provider 启动回环服务。POST /receive 接收 limit，返回 messages 与逻辑秒 now；每次投递赋予新的 receipt_handle 和十秒租约，delivery_id 保持不变。POST /renew、/ack 使用 receipt_handle，过期或旧句柄为 409。POST /clock 的 advance 推进逻辑秒，不需要真实等待。POST /control 的 drop_ack=true 让下一次确认在服务端落下后断开响应。GET /status 用于运维核对。事件沿用 Meterbook 的业务信封，另有一条格式不合法的合成投递。远端租约模型不替代本地采集进度。
